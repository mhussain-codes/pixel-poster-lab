# POSTER / LAB

A tiny generative art studio for making bold, downloadable posters. Remix abstract compositions, find a color mood, then share the exact design with a reproducible seed.

**[Open the live studio](https://mhussain-codes.github.io/pixel-poster-lab/)** · [View the source](https://github.com/mhussain-codes/pixel-poster-lab)

## Make a poster

1. Write a headline and small-print line.
2. Pick a color mood and composition, or leave composition on **Surprise me**.
3. Change the seed to make a new design. Reuse a seed to recreate it.
4. Save a crisp PNG or copy a shareable link.

## What’s inside

- Three original generative compositions: orbit, sunburst, and wave field
- Four color moods
- Share links that preserve the poster settings
- High-resolution PNG export
- Responsive layout; everything runs locally in your browser

## Built with

Vanilla HTML, CSS, JavaScript, and the Canvas API. No dependencies, accounts, or uploads.
